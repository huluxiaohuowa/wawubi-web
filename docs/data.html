基础输入与词库

基本 86 五笔查码使用设备上的码表。用户词库和候选排序在设备保存。导入的词库属于你的本地数据，公开反馈前请先检查内容。

会访问哪些外部服务

操作 数据去向
在线词库搜索或下载 选中的词库来源，搜狗搜索会发送查询词
iCloud 同步 你 Apple 账户的 iCloud 容器
云语音转写 你选择的转写服务商
Mac 云联想、问字和翻译 默认关闭。开启后，补全请求会将本次拼音或五笔候选，以及同一输入框内刚由 WA 五笔上屏的部分文字发给你配置的服务商。问字和翻译发送手动提交的文字。
Mac 语言学习 内置英语释义在设备上查找。开启云端译词后，缺少本地释义的候选才会发给你配置的服务商。
检查更新 GitHub 或更新器使用的加速源

密钥与权限

语音和云联想的服务密钥保存在本机钥匙串。系统麦克风、语音识别和 iOS 完全访问由系统控制，需要在每台设备分别授权。

iOS 正式政策

iPhone 与 iPad 的完整政策在 隐私政策页。此文用于解释功能边界，不替换正式政策。
