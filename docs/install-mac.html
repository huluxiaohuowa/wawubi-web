安装 Mac 版

从 DMG 安装输入法，为当前账号添加输入源。

适用 macOS 13 及以上，Apple 芯片与 Intel

下载安装

  1. 前往 下载页 获取 Mac 版 DMG。
  2. 打开 DMG，双击「安装 WA 五笔」，按提示完成管理员授权。
  3. 安装器将输入法安装到系统输入法目录，一次安装供本机所有账号使用。

添加输入源

  1. 打开「系统设置 → 键盘 → 文本输入 → 编辑」。
  2. 点击添加，在「简体中文」中选择 WA 五笔。
  3. 从菜单栏的输入菜单切换到 WA 五笔。其他账号首次使用时，也要各自添加输入源。

列表中暂时找不到

首次安装后，如果「简体中文」列表没有刷新，保存正在进行的工作，注销后重新登录，再回到系统设置添加输入源。

开始输入

在一个普通文本框中输入 ggtt，用空格选择「五笔」。然后查看 第一次输入，熟悉选字、翻页和中英切换。
