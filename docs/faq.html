安装后找不到 Mac 输入源

先到系统设置的文本输入列表中添加 WA 五笔。首次安装后如果简体中文分类中没有出现，保存工作，注销并重新登录，再添加。完整步骤见 安装 Mac 版。

Enter 怎么没有选首词

默认 Enter 提交英文编码，空格选择首选。在「设置 → 输入 → Enter 键」中可以选择上屏候选。分号、单引号和第五键上屏也有各自的开关。

自动加词没有记住

先确认已开启「从拆字输入自动加词」。该功能需要删掉未选中的四码，再逐字上屏，组合编码与原编码吻合。iOS 键盘保存学习结果还需要完全访问。也可打开用户词库手动添加。

语音没有开始录音

先检查语音已开启、快捷键正确，并且麦克风和语音识别权限可用。选云服务时还要确认服务地址、模型和密钥。首次设置可先使用 Apple Speech 测试。

词库或设置没有同步

检查两台设备的 Apple 账户与 iCloud Drive，再分别点击立即同步查看状态。密钥和系统权限不会随词库同步，需要在每台设备配置。

怎样反馈问题

通过 GitHub Issues 描述系统版本、WA 五笔版本、输入方案、相关开关、复现步骤与预期结果。可以用无敏感内容的词句演示问题。不要在公开问题中发送密钥、私人词库或录音。
