按键速查

候选选择、模式切换、词库编辑和设置入口的快捷键。

适用 Mac 版

本页内容
选择与翻页切换与辅助输入词库与候选设置与语音

选择与翻页

按键 作用
空格 上屏首选
数字 1–9 选择指定候选
分号 / 单引号 选第二项 / 第三项，单键时分号选键名汉字
- / = 或 [ / ] 候选翻页
Enter 默认提交英文编码，可在设置中改为上屏候选

切换与辅助输入

按键 作用
轻按 Shift 切换中英文
反引号 临时拼音，候选旁显示五笔编码
空闲时分号 临时英文、日期或金额输入
z + 空格 / zz 重复上次输入 / 符号
Control + Option + T 切换简繁输出
Control + . 切换中英文标点

词库与候选

按键 作用
Control + 数字 候选置顶
Control + Shift + 数字 隐藏候选
Control + = 快捷加词
Control + - 隐藏最近输入的候选，可使用选中文本

设置与语音

按键 作用
Control + Option + Command + [ 打开设置
Control + Option + Command + ] 打开用户词库
按住 Control + Shift，松手 启用语音后，录音并转写。快捷键可自定义

分号、单引号、Shift、Enter、第五键上屏等行为可以在设置中调整。本表描述默认或对应开关启用后的行为。
