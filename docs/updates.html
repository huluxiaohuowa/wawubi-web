更新 Mac 版

从输入法菜单手动检查更新，或在设置中开启自动下载并安装。下载通过校验后安装，系统可能请求管理员授权。

也可从 下载页 获取当前安装包，按安装器提示更新。

下载慢或获取失败

Mac 更新器优先通过 GitHub 获取，失败后会尝试加速源。网络仍不通时，可以稍后重试，或直接查看 GitHub Releases。

更新后检查什么

  • 确认输入法菜单中的版本与刚安装的版本一致。
  • 在普通文本框测试选词、上屏和中英文切换。
  • 检查原有用户词库、候选调整和偏好。遇到问题先保留数据，再反馈。

更新 iOS 版

iOS 版通过 App Store 更新。商店页面提供当前版本与设备要求。
