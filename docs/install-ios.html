从 App Store 安装

打开 WA 五笔 App Store 页面，查看设备与系统要求并安装。安装完成后打开 WA 五笔主 App。

添加系统键盘

  1. 打开「设置 → 通用 → 键盘 → 键盘 → 添加新键盘」。
  2. 选择 WA 五笔。也可以从 WA 五笔主 App 的「设置 → 系统键盘」打开系统设置。
  3. 在文字输入框中长按地球键，选择 WA 五笔。

完全访问有什么作用

允许完全访问后，键盘扩展可以把自动加词等编辑写入与主 App 共用的 App Group 词库。键盘扩展本身不访问麦克风。语音功能在主 App 中使用，详见 语音输入。

权限可以随时到系统键盘设置里调整。数据处理方式见 iOS 隐私政策。
