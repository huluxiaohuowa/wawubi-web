五笔、拼音与混合方案

在输入法菜单或「设置 → 输入 → 编码方案」选择五笔、拼音或五笔拼音混合。只临时查一个不会拆的字时，可以按反引号进入临时拼音，候选旁会显示五笔编码。

临时英文与转换

在空闲时按分号，或输入大写字母，可以进入临时英文。分号模式里输入 2026-11-19 或 123.45 后确认，可得到中文日期或大写金额。

「设置 → 输入」里可以开关分号临时英文、z 键功能和空码后转英文。

繁体与标点

Control + Option + T 切换简体与繁体输出。Control + . 切换中英文标点。在「设置 → 标点」可以选择中文、英文或自定义方案，并设置直角引号、成对引号和单个符号的输出映射。

需要进一步补全、问字或翻译选中的文字时，可按需配置 云联想。云端能力默认关闭。

不同应用默认使用不同语言

  1. 打开「设置 → 应用规则」。
  2. 添加应用，也可以将应用拖入列表。
  3. 为每个应用选择默认中文或英文。进入已绑定的应用时，WA 五笔按规则启动。
