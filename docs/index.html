从哪里开始

  • 还没安装？先看 安装 Mac 版 或 添加 iOS 键盘。
  • 刚装好？从 第一次输入 练习选词和上屏。
  • 想知道某个键的作用？打开 按键速查。
  • 想带上词库与设置？查看 词库管理 和 iCloud 同步。
  • 想在选字时查看译词？阅读 语言学习。需要云端辅助时，查看 云联想、问字与翻译。
  • 遇到问题？先看 常见问题，再按说明反馈。

选择你的平台

平台 入门方式 设置入口
Mac 下载安装 DMG，添加 WA 五笔输入源 输入法菜单中的设置
iPhone / iPad 从 App Store 安装，再到系统设置添加键盘 打开 WA 五笔主 App 的设置

这套文档怎么读

每篇文档先说明适用平台，再给出设置位置、操作步骤和预期结果。Mac 版设置较多，iOS 版键盘与系统权限也有独立的说明。网页上的在线试打只用于体验 86 五笔查码，上屏和网站交互不会更改你设备上的输入法设置。

先体验，再设置

在线试打 可以输入 ggtt 查找「五笔」，输入 ltif 查找「输入法」。想试外观，可打开 主题体验。
