手动添加词条

打开输入法菜单中的用户词库，或使用 Control + Option + Command + ]。输入词条后会自动填写编码，需要时可在右栏手动修改，再点击保存。

Control + = 可快捷加词。使用之前请确认要保存的是当前候选或选中的文字。

从拆字输入自动加词

从 macOS 0.1.32 起，两种自动加词方式都在「设置 → 词库 → 自动加词」，可分别开启。

  1. 开启「删码重打时自动加词」。
  2. 整词打不出来时，删掉未选中的四码。
  3. 逐字选择并上屏，组合出的 86 五笔编码与原编码吻合时，会加入用户词库。

开启「连续上屏时自动组词」后，连续上屏的完整五笔字词会按全码组词并加入用户词库。最大词长默认 4 字，可调至 2–10 字。

用微信练习

例如输入 tmwy 后没有找到需要的「微信」，删掉编码，再分别选「微」和「信」。编码吻合后，下一次可用 tmwy 输入整词。

学习结果进入用户词库，可回到编辑窗口查看。自动加词依赖前后的输入过程，未满足条件时可以改用手动加词。

带到另一台设备

用户词库可以参与 iCloud 同步。在 iOS 系统键盘中保存学习结果，还需要允许完全访问。
