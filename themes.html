候选窗主题

纸白或松墨，横排或竖排。先在这里比较配色、布局与字号，再把喜欢的外观带到 Mac 版。

候选布局

喜欢的外观可以导出为文件，换一台 Mac 后再导入。

主题文件

下载预设后，在 Mac 版「设置 → 外观 → 导入外观…」选择 JSON 文件。这些预设只包含配色、透明度、字号和布局。

保存自己的外观

  1. 在 Mac 版设置中选主题，调整 14–28 pt 字号、40%–100% 不透明度和横竖布局。
  2. 点击「导出外观…」，保存文件。
  3. 在另一台 Mac 中导入。候选数量等其他输入设置仍在对应设置页调整。
查看外观文件格式 
{
  "theme": "paper",
  "opacity": 1,
  "fontSize": 22,
  "vertical": false
}

theme 可用 system、ink、paper 或 indigo。请使用应用导出的结构，避免添加无效字段。
